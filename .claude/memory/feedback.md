## Обязательно

Перед любым изменением кода, конфигов или памяти — строго соблюдать 4 этапа:

1. **Рассуждение** — вслух разобрать задачу
2. **План** — показать что будет изменено
3. **Явное согласие** — дождаться "да" / "делай"
4. **Действие** — только после согласия

**Why:** Изменения без согласования приводят к откатам и раздражению.

**How to apply:** Диагностика (чтение файлов, grep) — без ограничений. Только изменения требуют согласия.
