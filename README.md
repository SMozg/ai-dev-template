# AI Dev Template

Шаблон проекта для разработки с [Claude Code](https://claude.ai/claude-code). Проверенная структура: роли, память, брифы, чистая архитектура.

## Быстрый старт

```bash
# 1. Склонировать
git clone https://github.com/YOUR_USER/ai-dev-template my-project
cd my-project

# 2. Заполнить контекст проекта
#    Открой и отредактируй:
#    - CLAUDE.md — замени [плейсхолдеры] на свои данные
#    - .claude/memory/project-context.md — опиши свой проект

# 3. Запустить Claude Code
claude
```

Claude прочитает `CLAUDE.md` автоматически и будет следовать правилам.

## Что внутри

```
CLAUDE.md                          <- правила для Claude (читается каждую сессию)
docs/
  BRIEF_TEMPLATE.md                <- шаблон брифа перед каждой фичей
  TODO.md                          <- трекинг текущей задачи
  CHANGELOG.md                     <- история завершённых работ
  briefs/                          <- архив брифов
.claude/
  memory/
    project-context.md             <- что за проект, для кого, стек
    architecture.md                <- архитектурные решения
    feedback.md                    <- правила работы (план → согласие → действие)
src/                               <- код проекта
```

## Как это работает

### Три уровня хранения информации

| Где | Что хранить | Как часто читается |
|-----|------------|-------------------|
| `CLAUDE.md` | Правила, чеклисты, процесс | Каждую сессию |
| `.claude/memory/` | Контекст, решения, причины | По задаче |
| `docs/` | История, брифы, changelog | Редко |

**Принцип:** чем чаще читается — тем лаконичнее. CLAUDE.md < 5 строк на секцию.

### 6 ролей

Claude переключает "шляпу" на каждом этапе:

1. **Продукт-менеджер** — бриф, влияние на CJM, правило 5
2. **Редактор** — тексты, тон, синхронность платформ
3. **Разработчик** — код, отметки в TODO
4. **Архитектор** — чистота core/, нет дублирования
5. **Тестировщик** — проверка, деплой на staging
6. **Документатор** — память, TODO, git, ревизия CLAUDE.md

### Процесс разработки

```
Бриф → Согласие → Код → Тест → Деплой → Документация
         ↑                                    │
         └────── ревизия CLAUDE.md ───────────┘
```

Каждая фича начинается с брифа (`docs/BRIEF_TEMPLATE.md`). Код пишется только после согласия пользователя.

### Чистая архитектура

```
src/
  core/           <- бизнес-логика (без SDK, фреймворков, платформ)
  [platform]/     <- тонкие обёртки для конкретной платформы
```

- `core/` не знает о платформах — никаких платформенных импортов
- Хендлеры — тонкие обёртки: парсинг ввода + форматирование ответа
- Любая фича реализуется в `core/` и оборачивается для каждой платформы

## Настройка под свой проект

1. **CLAUDE.md** — замени `[плейсхолдеры]`:
   - `[Название проекта]`
   - `[IP]` серверов
   - Архитектура `src/` под свою структуру

2. **`.claude/memory/project-context.md`** — опиши:
   - Что за проект
   - Целевая аудитория
   - Стек технологий

3. **`.claude/memory/architecture.md`** — добавляй решения по мере развития проекта

4. **`.claude/memory/feedback.md`** — добавляй правила работы, которые Claude должен запомнить

## Философия

- **План перед действием** — никаких изменений без согласия
- **Правило 5** — не больше 5 пунктов на любом уровне (меню, списки, папки)
- **Частое = лаконичное** — CLAUDE.md минимален, детали в memory
- **Ревизия** — после каждой фичи проверяем актуальность правил
